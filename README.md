# 灵枢 · 本地 AI 工作台

> 两个本地模型，一个网页工作台。对话不联网、出图不排队、作品不上传。

灵枢是一个**完全跑在自己电脑上的 AI 桌面软件**，中间由一个本地网关（FastAPI）串起来，界面是内嵌浏览器的桌面窗口。装好之后双击就能用，不注册、不登录，断网也能对话和出图。

- 平台：Windows 10 / 11（64 位）
- 形态：绿色免安装，解压即用
- 桌面壳：`灵枢.exe`（自带 Python 运行时与浏览器内核，**不需要装 Python**）
- 推理后端：llama.cpp（对话）、stable-diffusion.cpp（出图），都随包附带
- 隐私：默认不联网；只有你手动勾选「联网搜索 / 读取网页」时才会访问网络

## 一、它能干什么

| 页面 | 能力 |
|---|---|
| **运行** | 一眼看清本机显卡、显存、CPU、内存、磁盘；自动算出该用多少层上卡、多大上下文、多少线程；实时显存曲线；启停模型；拖入新模型 |
| **对话** | 本地大模型聊天，支持系统提示词、采样参数、思考模式、附件、工具调用（时间 / 计算器 / 读文件 / 写文件 / 联网搜索 / 读网页）、会话搜索与导出 Markdown |
| **Agent** | 描述一个任务，它先给计划再执行；权限三档：只读 / 只改工作区 / 完全权限；执行过程有记录 |
| **画图** | 文生图：5 种比例 × 3 档清晰度、1–4 张、步数与种子可控；作品历史支持「再来一张（同种子）」和「去画布」 |
| **画布** | 以某张作品为底图，涂抹要改的区域后局部重绘（1:1 / 1024²） |
| **设置** | 模型开关与模型管理、采样参数、上下文长度、出图路径、外观切换、本机配置抽屉（引擎版本 / 三个端口 / 端口冲突提示） |

几个实际用起来有感的设计：

- **不会一开软件就吃满显存**：双击后只有界面起来，两个模型都是「已关闭」，你点哪个才加载哪个。
- **硬件自动适配**：不用手填 `-ngl`、上下文、线程。软件启动时探一次显卡和模型头信息，自己算参数；放不进显存就按比例分层，没有 NVIDIA 卡会降成纯 CPU 并在界面写明原因。
- **显存不够就不让你点**：8 GB 卡上装不下对话 + 画图两条权重链时，「启动全部模型」按钮会直接隐藏并说明需要多少显存。
- **模型文件拖进去就行**：把 `.gguf` / `.safetensors` 拖到运行页的框里，自动上传进 `models`；传完会问你要不要删掉本机那份重复的原文件（删除进回收站，可还原）。
- **模型管理**：列出 `models` 里所有文件、大小、是否正在使用；不用的可以一键删除，正在被配置引用的会拦住，避免删了下次启动缺文件。
- **关掉就真释放**：关模型 = 停进程 + 放显存 + 释放端口，不留后台常驻。

## 二、系统要求

| 项 | 最低 | 建议 | 说明 |
|---|---|---|---|
| 系统 | Windows 10 64 位 | Windows 11 64 位 | 需要 `.NET`/VC 运行库齐全的常规系统 |
| 显卡 | NVIDIA，显存 6 GB | NVIDIA，显存 8 GB 及以上 | 驱动 ≥ 527（随包是 CUDA 12 的 ggml 库）；8 GB 是"对话或画图二选一同时只跑一个"的舒适线 |
| 内存 | 8 GB | 16 GB 及以上 | 出图模型要往内存里搬一部分；低于 8 GB 会拒绝启动画图模型 |
| 磁盘 | 20 GB 空闲 | 30 GB 以上 | 整包 18.9 GB，出图作品还会继续占 |
| 路径 | **纯英文路径** | 例如 `D:\Lingshu` | 放在 `C:\Program Files` 或中文路径下，C++ 后端可能打不开模型 |
| 端口 | 8000 / 8081 / 8099 空闲 | — | 被占用时软件会明确提示，可改 `config.yaml` |

> 没有 NVIDIA 显卡也能打开界面和对话（纯 CPU），但出图基本不可用；AMD / Intel 显卡暂不支持加速。

## 三、下载后怎么用

1. **解压**到一个**纯英文路径**，例如 `D:\Lingshu`。不要只把 `灵枢.exe` 拖出来——界面、后端、模型都在它旁边的文件夹里。
2. **双击 `灵枢.exe`**。
   - 首次启动会被 Windows SmartScreen 拦一次（exe 未做数字签名）：点「更多信息」→「仍要运行」。杀毒软件也可能扫描解压，第一次会慢十几秒到一分钟。
   - 窗口出现后先看到「运行」页，此时只有界面起来了，模型还没加载。
3. **启动一个模型**：
   - 想聊天：设置页「模型与服务」→「启动对话模型」，首次加载约 10–60 秒。
   - 想画图：→「启动画图模型」，首次加载约 20–120 秒（加载瞬间显存会冲高一次，属正常）。
4. **开始用**：对话页直接发消息；画图页写一句中文描述，点生成。
5. **关闭软件**：直接关窗口。它会先停推理进程、释放显存和端口，不会留孤儿进程。

> 打开软件后如果左下角显示红点「gateway 未连接」，多半是端口被别的程序占了：换个端口（改 `config.yaml` 的 `gateway.port`）或关掉占用者再启动。

## 四、界面导览

顶部导航五个入口：**运行 · 对话 · Agent · 画图 · 设置**。

- **运行**：本机概览、显存曲线、服务与队列、模型与服务（启动 / 关闭 / 拖入 / 管理）、运行日志。
- **对话**：左侧是会话列表（可搜索、可改名、可导出、可删除），右侧是聊天区；输入框下方有「工具」「对话设置」「对话参数」。
- **Agent**：输入任务 → 看计划 → 看执行记录；右下角可以选权限范围与对话模型。
- **画图**：左表单右结果；右上角「历史」里能改名、删除、再来一张、送去画布。
- **设置**：模型开关、模型管理、生成参数、出图/日志/聊天目录、外观、关于；右上角「本机配置」抽屉里有硬件明细、引擎版本和三个端口。

### 图片和会话存在哪

| 内容 | 位置 |
|---|---|
| 出图作品 | `output\`（每张 png 旁边有同名 json，记录提示词、种子、步数、尺寸） |
| 会话 | `chats\`（一条会话一个 json；导出是 `chats\exports\*.md`） |
| 日志 | `logs\`（含显存采样 `gateway.vram.csv`） |

## 五、模型管理

- **拖入**：运行页「模型与服务」下方有个拖入框，`.gguf` / `.safetensors` 拖进去即可上传到 `models`，带进度条；同名文件会先问你覆盖不覆盖。
- **提醒删源**：上传完成后会弹窗列出本机其它位置（桌面 / 下载 / 文档）的同名同大小文件，问你要不要删掉，避免一个模型占两份空间（删除走回收站）。
- **管理**：卡片右上角「管理模型」列出全部文件、大小、是否正在使用；可删不用的，正在被配置引用的会灰掉。
- **换模型**：当前发布包带一套对话模型 + 一套画图模型（含文本编码器、图像投影、VAE）。加别的模型文件可以在下拉里切换，但要用全新的模型组合，仍需改 `config.yaml` 的 `models` 段后重启。

## 六、隐私与联网

- 对话、出图、Agent 全部在**本机**完成，不上传任何内容，不需要账号。
- 默认不联网。只有你在对话页「工具」面板里**手动勾选**「联网搜索」或「读取网页」时，才会访问网络（搜索走 Bing 中国站，读网页只取正文），此时发送的是你那条查询的文本。
- 没有遥测、没有后台自动更新、没有开机自启。
- 想彻底删干净：删掉整个 `灵枢` 文件夹即可（软件不写注册表；桌面快捷方式是 Windows 自己记的）。

## 七、常见问题

**Q：双击没反应 / 弹出红色警告？**
A：SmartScreen 因为 exe 未签名会拦一次，点「更多信息 → 仍要运行」。若杀软直接拦截，加入信任后重试。

**Q：界面出来了，但发消息说模型已关闭？**
A：这是设计如此——模型要手动启动。去设置页「模型与服务」点「启动对话模型」，等状态变成「就绪」。

**Q：为什么「启动全部模型」按钮不见了？**
A：你的显存不足以同时装下对话和画图两条权重链（8 GB 卡约需 16 GB）。分别启动即可，用完一个关一个。

**Q：画图很慢 / 报显存不足？**
A：8 GB 卡建议 1K + 1 张；2K/4K 或 2–4 张会成倍吃显存和时间。关掉浏览器、壁纸引擎、游戏再试，运行页能看到实时可用显存。

**Q：能不能一边对话一边画图？**
A：8 GB 显存不建议；显存更大的卡可以，软件会按实测显存判断该不该给你「启动全部」的入口。

**Q：能换成自己的模型吗？**
A：可以拖进 `models` 并在下拉里选择；完全自定义组合需改 `config.yaml` 后重启。

**Q：为什么提示路径不能有中文？**
A：C++ 推理后端对非 ASCII 路径兼容性差，可能打不开模型文件。把整个文件夹放到 `D:\Lingshu` 这类纯英文路径下最稳。

**Q：端口冲突怎么办？**
A：`config.yaml` 里改 `gateway.port` / `sd.port` / `llama.port`（默认 8000 / 8081 / 8099），改完重启软件。设置页「本机配置」会显示当前端口与冲突提示。

**Q：卸载 / 清理？**
A：删整个文件夹。若要保留作品和会话，先把 `output\`、`chats\` 拷走。

## 八、已知限制（如实说明）

1. 出图 2–4 张是**串行**，不是并行：单卡按顺序跑，时间和显存按倍数算，显存不足时后面的会被护栏中止（前面成功的保留）。
2. **反向提示词在当前 turbo 出图模型下不生效**（`cfg_scale=1.0` 时不参与计算），只会记进作业信息。
3. 上下文长度可调到 32K，但 8K 以上只验证过"能起、能出"，没做长文质量与显存峰值标定。
4. 4K 出图在 8 GB 卡上可能直接失败并报错，属显存限制而非 bug。
5. 软件未做代码签名，首次运行必被 SmartScreen 提醒一次。
6. 模型体积决定了整包大小，这是"离线可用"的代价；不想带这么多可在 `models` 里删掉用不到的模型（管理面板可查大小）。
